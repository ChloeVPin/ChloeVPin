# Chloe Valesquez

I am an independent software builder in Los Angeles. I make desktop software, developer tools, and research tools around focused problems.

## Selected work

- [launchdx](https://github.com/ChloeVPin/launchdx) diagnoses macOS app launch failures from local signing, quarantine, and installer evidence.
- [Tempo](https://github.com/ChloeVPin/tempo) provides immutable date and time types for TypeScript.
- [BoundaryBench](https://github.com/ChloeVPin/boundarybench) studies authorization preservation in tool-using agents. Its deterministic harness is separate from model observations.
- [Open Agent Skills](https://github.com/ChloeVPin/open-agent-skills) contains standalone instructions for coding-agent work.
- [env-clinic](https://github.com/ChloeVPin/env-clinic) compares environment files and reports missing, extra, and empty variables.

More work is in the [repository list](https://github.com/ChloeVPin?tab=repositories) and on [my website](https://chloevalesquez.vercel.app).
