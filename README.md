# Chloe

**Software developer building native tools, developer infrastructure, and focused open-source products.**

I like software with a clear job, explicit boundaries, and fewer layers between the user and what the system is doing. My public work spans native desktop software, developer tools, and libraries.

## Selected work

| Project | What it is |
| --- | --- |
| [Tempo](https://github.com/ChloeVPin/tempo) | Immutable, Temporal-aligned date and time library for JavaScript and TypeScript |
| [Tilly](https://github.com/ChloeVPin/Tilly) | Native macOS uninstaller built around reviewable, conservative file discovery |
| [launchdx](https://github.com/ChloeVPin/launchdx) | Read-only macOS launch diagnosis for signing, notarization, Gatekeeper, and bundle evidence |
| [Kiri](https://github.com/ChloeVPin/kiri) | Cross-platform desktop runtime exploring direct platform ownership and measurable overhead |
| [Castle](https://github.com/ChloeVPin/Castle) | Cargo-inspired C++ project manager with direct Clang builds and an optional CMake backend |
| [Popcord](https://github.com/ChloeVPin/popcord) | Native macOS menu bar companion for Discord built with Swift and WebKit |

## How I build

- Prefer evidence over assumptions.
- Keep safety and security boundaries visible.
- Use native platform capabilities when they earn their complexity.
- Keep tools focused enough that their behavior remains understandable.
- Treat performance claims as measurements, not branding.

Smaller utilities, experiments, and reusable development tooling are available in the [repositories tab](https://github.com/ChloeVPin?tab=repositories).
